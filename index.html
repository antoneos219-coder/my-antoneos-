HTML5 هيكل صفحات الويب

لغة ترميز تصف بنية محتوى صفحة الويب باستخدام عناصر ووسوم واضحة.

الاستخدامات والمميزات

  • هيكلة الصفحات
  • عناصر دلالية
  • تنظيم المحتوى
شرح HTML والمثال البرمجي

ما هي؟ ولماذا نستخدمها؟

HTML هي لغة توصيف النص التشعبي. تحدد معنى أجزاء الصفحة وترتيبها، وهي الأساس الذي تُبنى عليه صفحات الويب.

أين تُستخدم؟

في صفحات ومواقع الويب، لوضع العناوين والفقرات والصور والروابط والنماذج.

مثال وشرحه

<h1>مرحباً بالعالم</h1>

ينشئ الوسم h1 عنواناً رئيسياً. HTML تصف المحتوى، بينما CSS تنسّق مظهره وJavaScript تضيف التفاعل.

3

CSS3 التصميم والتنسيق

لغة تنسيق تتحكم في ألوان العناصر وتخطيطها وخطوطها واستجابتها للشاشات.

الاستخدامات والمميزات

  • التصميم
  • Flexbox وGrid
  • تجاوب الشاشات
شرح CSS والمثال البرمجي

ما هي؟ ولماذا نستخدمها؟

CSS هي أوراق الأنماط المتتالية. تفصل شكل الصفحة عن بنيتها، مما يجعل تعديل التصميم وإعادة استخدامه أسهل.

أين تُستخدم؟

لتنسيق صفحات الويب، وبناء التخطيطات المتجاوبة باستخدام Grid وFlexbox.

مثال وشرحه

p { color: gold; }

يختار المحدد p الفقرات ويجعل لون نصها ذهبياً. بخلاف HTML، تحدد CSS طريقة العرض لا بنية المحتوى.

لغة برمجة تضيف السلوك والتفاعل إلى صفحات الويب وتتعامل مع عناصر الصفحة.

الاستخدامات والمميزات

  • DOM
  • الأحداث والمنطق
شرح JavaScript والمثال البرمجي

ما هي؟ ولماذا نستخدمها؟

JavaScript لغة برمجة تُستخدم لإضافة المنطق والتفاعل، وتعمل في المتصفحات إلى جانب HTML وCSS.

أين تُستخدم؟

في تفاعلات المواقع وتحديث محتوى الصفحة ومعالجة أحداث المستخدم.

مثال وشرحه

const name = "Antonios";
console.log(`Hello, ${name}!`);

يحفظ const الاسم في متغير ثابت، ثم تعرض console.log رسالة الترحيب. على عكس CSS، تستطيع JavaScript تنفيذ منطق والاستجابة للأحداث.

لا توجد نتائج مطابقة. جرّب كلمة بحث أخرى.
